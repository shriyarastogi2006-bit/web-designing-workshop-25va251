# Taskflow

A polished to-do list application built with only HTML, CSS, and vanilla JavaScript.

## Features

- Add, edit, complete, and delete tasks
- Due dates and low, normal, or high priorities
- All, active, and completed filters
- Instant task search
- Sort by creation date, due date, or priority
- Completion progress indicator
- Clear all completed tasks
- Light and dark themes
- Responsive mobile and desktop layout
- Browser `localStorage` persistence
- Keyboard and screen-reader-friendly controls

## Run

Open `index.html` in any modern browser. No installation, build process, or internet connection is required for the application logic.

The Google font request gracefully falls back to system fonts when offline.
